# Security Policy

## Reporting Vulnerabilities
Please report security issues to security@maksimtech.com (GPG key on keys.openpgp.org)

## Known Open CVEs
All currently open CVEs affect Debian Bookworm system packages (OpenSSL, Perl, util-linux, zlib).
These are unrelated to MailRadar's Python codebase and are pending Debian security backports.
They will be automatically patched on the next Docker build after Debian releases the fixes.
